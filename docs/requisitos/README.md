## Como ler

Cada funcionalidade é uma história de usuário (US), com descrição, critérios de aceitação em cenários Dado / Quando / Então (C1, C2…) e regras de negócio específicas (RNE). Regras gerais (RNG) e comportamentos comuns (CM) ficam no 00. Para citar um critério num teste ou commit, use o formato "US002, C4".
